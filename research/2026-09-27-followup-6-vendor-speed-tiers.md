# Follow-up 6 — Vendor speed tiers and computer-use latency (dossier §8.3 item 6)

**Date:** 2026-09-27 · **Dossier base:** `Agent-Acceleration-Consolidated-Dossier-v2.1-2026-09-27.md` (E1–E93, D1–D94) · **Patch targets:** §1.7 (E76–E88), §4.4, plus consequential lines in §0.4 item 8, §1.3 (E36/E37) and §8.1 · **New IDs (provisional):** EF6-1 … EF6-22, DF6-1 … DF6-7

**Method.** Each source was read with a web-fetch tool that extracts page text and answers through a small model. Every quote below was requested verbatim; where the tool returned a paraphrase, the entry says so. `openai.com` (index posts, `api-priority-processing`, help centre) returned HTTP 403, and `developers.openai.com/api/docs/guides/priority-processing` (the E77 URL) returned HTTP 404 twice. OpenAI claims were therefore taken from the OpenAI API changelog and pricing pages (both primary and reachable), the OpenAI Developer Community staff post, and labelled secondaries. X/Twitter is robots-blocked. Charts were not inspected as images. Where only image alt text carries a number, the entry says so. About 40 fetches and 15 searches were used.

**Labels.** *Vendor-stated* = a vendor's claim about its own product (vendor-marketing when it is on a launch/marketing page). *Third-party measured* = Artificial Analysis (AA) or another party's own measurement. "calc." = arithmetic done here. Throughput (tokens/s), TTFT, per-call latency and end-to-end task wall-clock are kept apart throughout.

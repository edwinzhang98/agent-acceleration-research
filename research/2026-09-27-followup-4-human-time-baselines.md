# Follow-up 4 — Human-time baselines: which benchmarks time humans, and where a clean agent-vs-human wall-clock ratio exists

**Date:** 2026-09-27 · **Scope:** dossier Part VIII §8.3 item 4 · **Dossier base:** `Agent-Acceleration-Consolidated-Dossier-v2.1-2026-09-27.md` (E1–E93, D1–D94) · **Patch targets:** §1.1 (E5, E12, E14, E15, E16; new rows) and §8.1 first bullet · **Provisional IDs:** EF4-1 … EF4-11, DF4-1 … DF4-6 (renumber to E94+ / D95+ at merge).

**How sources were read.** Web fetch of arXiv HTML for the stated version (answers extracted by the fetch tool, which was asked for verbatim quotes with locations). Two PDFs (APEX-Agents v3, AXIS ACL 2025) were downloaded by the fetch tool and their text extracted locally with `pypdf`; quotes from those two are exact text. Where the fetch tool returned a value but not a verbatim sentence, the entry says so. About 38 fetches/searches in total.

**Classification used in column (a) "how the human time was obtained".**
- **Timed, instrumented** — the time comes from a logging tool or start/finish buttons in the study software.
- **Timed, method not reported (NR)** — the paper says people performed the task and their time was recorded, but not how.
- **Self-reported actual** — people reported how long they took on the real task, after the fact.
- **Estimate** — a person (author, task writer, expert) states how long the task *would* take; nobody is timed.
- **Mixed** — both appear, or the wording supports both readings.

The dossier's §0.3 rule 4 only separates "estimate" from "stopwatch"; the middle three classes matter here (see still-open item 12).

### 1b. Where a clean agent-vs-human wall-clock ratio can be computed

A ratio is **clean** when four conditions hold: (i) the same task instances are used; (ii) the human time is timed, not estimated or self-reported; (iii) the agent time is end-to-end wall-clock; (iv) both sides are conditioned on success in the same way.

| Case | (i) | (ii) | (iii) | (iv) | Ratio (calc.) | Status |
|---|---|---|---|---|---|---|
| AXIS user study, UI agent (UFO, GPT-4 backend "version 20240513") vs manual | ✅ 5 tasks, same 20 people | ✅ instrumented | ✅ but includes the participant typing the command (inferred from App. C.1) | ⚠ Table 3 time is not stated to be conditioned on success; success differs (75/45% vs 100/97.5%) | **1.69× slower (L1), 0.93× (L2)**; AXIS API-first agent 0.29× / 0.34× of manual | **Cleanest found.** n is small, the order is not counterbalanced (manual first), and it is a 2024 agent on one app |
| CADWorld Table 10 | ✅ 6 tasks | ✅ logged demo | ✅ | ❌ agent side = fastest *successful* run; human = one expert demo | **1.47–4.28× slower** (geo-mean 2.40×; summed 2.19×) | A best-case bound, not a population ratio |
| FrontierFinance Table 3 | ✅ 10 tasks | ⚠ actual time, method NR | ✅ (per fetch tool; not verbatim) | ❌ agents score lower | **Agents 18.9× / 25.8× faster** | Long-horizon spreadsheet work. Agents faster but worse |

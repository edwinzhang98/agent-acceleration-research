# 2026-09-28 — Formulas that compute time or cost, across every vetted source

**Task (Edwin, 2026-09-28):** go through every source we have found so far — Part 1 and Part 2 of the deck, i.e. the whole of `slides/references.md` — and pull out every explicit formula that computes speed/latency or cost. Where a paper cites someone else's formula, follow the citation to the original, extract the formula from the original, and attribute it there (the original becomes the reference, not the citing paper). Reader-facing version (Chinese, with the formulas typeset): Claude Doc 《文献里的公式：算速度和成本的》, https://claude.ai/code/artifact/177ddf97-a4ed-4217-ab9c-686b5d0df45a.

**Method.** 83 arXiv papers + 6 non-arXiv sources (AXIS ACL 2025 PDF, Agentix NSDI 2026 PDF, Artificial Analysis methodology page, Anthropic pricing / prompt-caching / fast-mode pages, OpenAI pricing page, Anthropic best-practices blog). Eight Opus 5.5 subagents each read a batch via WebFetch of the arXiv HTML (PDF fallback when the HTML was truncated), made a second narrower fetch for every formula found, and followed citations on formulas to the original. This session (Fable) spot-checked Speculative Actions Prop. 1 and Thm. 7 against the PDF (match) and consolidated. The four "Not used" sources of the credibility rule were not scanned. Rate-limited and unread: GPA (arXiv:2604.01676v2). Versions and unread parts per source: §7 of the doc.

**Result.** 39 papers carry explicit time/cost formulas; 3 vendor/third-party pages carry billing or measurement definitions; 5 originals were reached by following citations (Cost-of-Pass, AndroidArena, Orca, vLLM, Anthropic Vision docs). The rest report measured numbers only. Every time model in the set has the same skeleton — per step: model generation + environment/tool execution, summed serially — and the acceleration papers add a term for how much can be overlapped. Every dollar-cost model is Σ (tokens of class c × price of class c). Only three metrics fold accuracy into cost or steps: WES (OSWorld-Human), Cost-of-Pass (Erol et al.), APGR/CPT (RouteLLM).

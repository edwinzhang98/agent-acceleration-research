DEFINITIONS AND SETUP

Task, environment and learning

Working definitions for a Web Agent with fixed model weights.

Web task
A goal, input data and an initial state, with an external check of successful completion.
Environment
The website interface, its rules and permitted actions. The website stays fixed while page and record states change during execution.
Execution
trajectory
The ordered observations, actions and tool feedback from a run, together with its outcome, elapsed time and cost.
Learning
A persistent update to knowledge, prompts or code that later tasks reuse. Model weights stay fixed.

One illustrative task

Upload failure Bug ticket
Goal

Create a Bug ticket with the supplied information.

Input

PDF upload fails.
Steps: choose report.pdf, then select Upload.

Initial state

Reset website, signed in with fixed permissions.

External success check

Saved fields match the request.
No duplicate ticket or unrelated change.

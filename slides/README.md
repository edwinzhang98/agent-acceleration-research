# slides/ — the boss deck

`agent-acceleration.html` is a self-contained HTML deck (open the file in a browser; ← → or click to move, B returns from an appendix page, `#s05` / `#t09` / `#b0-1` deep-link a page). `agent-acceleration.pdf` is the same deck, both parts, printed one page per slide (it replaced `agent-acceleration-part1.pdf` when Part 2 was added). Both are generated by `build_deck.py`:

```
python3 slides/build_deck.py --fonts slides/fonts      # writes agent-acceleration.html (IBM Plex embedded)
python3 slides/check_deck.py --pdf=slides/agent-acceleration.pdf   # fit check (every page must report content ≤ box and bad: []), screenshots to slides/shots/, PDF export
```

The PDF is exported with headless Chromium (Playwright: `page.pdf(width='1280px', height='720px')` with print media). Environment: a Python 3.12 venv at the repository root with the versions pinned in `slides/requirements.txt` — matplotlib 3.10.9 reproduces the committed math SVGs byte for byte (3.11 lays the formulas out slightly differently), Playwright 1.62.0 drives Chromium v1234. Set it up once with `uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r slides/requirements.txt && .venv/bin/playwright install chromium` (Playwright's browsers are shared across projects in `~/Library/Caches/ms-playwright`), then `source .venv/bin/activate` before the commands above. The deck is built from dossier v3 only, through the two Chinese study documents (《Agent 慢和贵的逻辑链》→ Part 1; 《Agent 加速：别人做到哪了》→ Part 2, not yet built).

## Conventions (agreed with Edwin 2026-09-27, after the ExpenseAI intro deck of 2026-09-22 as the style reference)

- Page anatomy: mono label top-left (`AGENT ACCELERATION · PART 1 · 07`), bold title, thin rule, a mono “from … → here … → to …” line, a light-blue callout with the page’s claim and the numbers it rests on, then cards / a table / small bar charts, a mono SOURCES line, and the appendix chip bottom-right. The thumbnail top-right is the loop diagram with the term(s) the page is about highlighted.
- Citations: author–year in the text — `(Abhyankar, Qi & Zhang, 2026)`, `(XLANG Lab, 2026)`, `(Anthropic, 2026b)` — and a full reference list at the end of the part (published version where one exists; otherwise arXiv number and the authors’ institutions). No source-type words (“preprint”, “paper”) on the slides; dossier E/D ledger IDs appear only in the Chinese speaker notes, never on the page.
- No attention-grabbing phrasing (Edwin, 2026-09-28: “不要搞标题党”): titles and claims state the finding in plain words — “Four accounting conventions for one task, and the cost of the environment machine”, not “the machines nobody counts”; no “honest answers”, “runs away”, “steep”, “kills”.
- Bold is for the claim, never for a number: each card leads with the point in bold and gives the figure, its conditions and the citation in regular weight beneath (Edwin, 2026-09-27: “要加粗的是观点不是例子”). Under each claim sits exactly one representative example — one number with its conditions, as a single bullet — not a list of them (Edwin, 2026-09-27/28: “先改成 bullet point”, then “例子砍剩一个有代表性的”); `card()` takes a list, and the list has one item. The paper-by-paper evidence lives in the appendix, which the card’s citation or the page chip points to. Pages 04 and 05 carry one small bar chart each, not three.
- Every number carries its measurement conditions in a full sentence (benchmark, task count, model, baseline, what was measured); our own arithmetic is marked “calc.”; vendor-stated speed multipliers are marked as such; vendor marketing is not cited.
- Mathematics: every formula and every variable on a page (N, J_i, |H_{a,i}|, the sums, the strips and pills) is typeset at build time with matplotlib mathtext (Computer Modern) into inline SVG by `tex()` / `nest_math()` / `eq_svg()` in the generator — no KaTeX or network at runtime, and the PDF matches the HTML.
- Plain words instead of jargon: “reading the prompt” / “writing the answer” (prefill / decode named once), “the harness — the program around the model”, “accessibility tree (the text list of on-screen elements)”, “elapsed time”, “cache of already-read prompt (the KV cache)”.
- Density: Edwin’s instruction of 2026-09-27 — the non-appendix part is about half of the first draft; roughly 200–300 words of body text per main page (chart labels included, references excluded); appendix pages are dense tables in the style of the reference deck’s appendix.
- Language: English on the pages; speaker notes were removed on 2026-09-28. The sources not used under the credibility rule (`references.md`, “Not used”) do not appear in the deck.

**Structure since 2026-09-28:** s00 is the unnumbered deck title (Agent acceleration), s01 the Part 1 title with its contents, s02 the loop with the variable and a page tag at each step plus four equation rows (time with the overlap term O, prompt growth, money by billing class plus machine hours, cost per success and the goal), each row credited to its source; Appendix A0 (2 pages) gives each row's source form and what the page leaves out. The thumbnail on pages 3–12 is page 2's loop in miniature. 24 pages; `check_deck.py` exempts s00 and s01. Speaker notes were removed on 2026-09-28 (Edwin: the deck will not be presented by him); the dossier IDs behind each number stay in the dossier and `research/`. Notation on page 2 (one for all rows; a source's own symbol where it exists and does not clash): overlap saving `T_saving` (AsyncFC), cache classes hit / miss (as in TokenPilot) and store (the vendors' cache write, renamed to avoid a clash with W); Appendix A0 quotes each source's formula in its own notation. Every page with a formula defines each symbol on the page.

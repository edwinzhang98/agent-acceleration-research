# 公式映射说明

`formulas.json` 是47个数学片段的精确源字符串到 LaTeX 映射。原报告共有50个反引号片段，另外3个 `not_found`、`click(index=5)`、`contact_name` 必须保留代码格式。`source` 不含反引号，SkillOpt候选选择式保留原字符串开头的一个空格。

`inline-math.json` 是23个指定段落的裸数学标识建议映射。它不是全局替换表：只在 `paragraphStartsWith` 指定的段落普通文本节点中应用，排除代码、链接及已有数学节点；先匹配较长 source，ASCII单字母必须有非字母数字/下划线边界。例如不可把 prompt 中的 p 改成数学节点。段落前缀保留 Markdown 粗体标记；若在 HTML 阶段匹配，应先去掉前缀的 Markdown 标记。

同形符号须按段落解释：第1节 θ 为模型权重，Trace 的 θ 为待编辑变量，Metis 的 θ 为次数阈值；Trace 的 τ 是反馈二元组，其他多处 τ 是任务轨迹；第9节成本式的 Σ 是求和，其他多数 Σ 是外部系统。成本式已用 `\sum` 解除这一混淆。

`provenance` 以报告是否对作者符号/算法做重命名、概括为准，有此类改写即保守标“本文改写”。SkillOpt补任务下标、MemRL排序的中文简写、HGM分支计数近似、VASO中文问题转逻辑式均有 notes 说明。段落中的“原文定义”标签不使这些简写成为逐字原式。

长式选择 display/aligned 仅为排版，没有添加训练损失、权重、费用惩罚或数学保证。VASO两式保留问号，表示待检查条件。回本式保留为比值近似，并须保留正文“分母为正且近似稳定”的条件。

KaTeX 中的中文 `\text{}` 需要本地中文字体 fallback；可在本地编译时处理 unicodeTextInMathMode 一类警告，不能通过删掉中文消除警告。所有源内容由本地报告转写，不依赖 CDN。
